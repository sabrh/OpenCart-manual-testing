# OpenCart Manual Testing

## Overview

This repository contains a complete manual testing portfolio for the OpenCart e-commerce application. The project demonstrates my understanding of the Software Testing Life Cycle (STLC), test documentation, and defect reporting.

The testing process was carried out by executing manually designed test scenarios and test cases against the OpenCart application. The resulting defects were documented through structured bug reports and mapped using a Requirements Traceability Matrix (RTM).

This project was completed as part of my practical learning in Software Quality Assurance.
